# Guia de Atendimento RNA

Guia de mensagens de WhatsApp para converter os leads do quiz da **RNA — Rosto Naturalmente Ativado**. Página HTML única, com mensagens prontas (botão "Copiar") organizadas em abas.

## Arquivo

- `guia-atendimento-rna.html` — a página completa (self-contained: HTML + CSS + JS inline). É só abrir no navegador.

## Artifact publicado

Versão renderizada (mesma fonte deste arquivo):
https://claude.ai/code/artifact/18bffbd7-7d59-4c4a-9dc6-8baa3ae4b458

## Abas

1. **💬 Follow-up** — Persona A (prevenção), Persona B (correção), meio-termo, ponte pós-Ritual.
2. **🎯 Fechar a Jornada** — para a cliente que já provou a técnica e pergunta o preço. Traz:
   - **⚡ Versão curta** — 5 balões prontos pra WhatsApp.
   - **📖 Versão completa** — 8 movimentos com a lógica de cada passo.
3. **📅 Reserva & No-show**
4. **❓ Dúvidas**
5. **🛡️ Objeções**
6. **🔄 Depois dos 90 dias**

## Estratégia da aba "Fechar a Jornada"

Desejo antes do preço. O número só aparece depois de instalar a âncora **avulsa × Jornada**
(12 sessões avulsas = R$ 2.940 → Jornada completa = R$ 1.800, 3x de R$ 600 = R$ 150/sessão).
Sem comparar com botox. Registro de prescrição, não de venda.
